# Common Core — 2022-23 ~ 2024-25 入学（30 学分制 v1）

> 适用入学年份：**2022-23、2023-24、2024-25**
> 总学分：**30**
> 来源：https://uce.ust.hk/web/courses_2025/curriculum.html（差异说明部分整理）
> ⚠ 注：官方未保留独立页面，以下结构依 2025-26 页面"2025-26 与 2022-23~2024-25 差异仅为新增 SUS 区域"的官方说明整理

## 结构总览

| 层 | 学分 | 必修/选修 |
|---|---|---|
| Foundations | 12-15 | CTDL 选修，其余必修 |
| Broadening | 12-18 | 必修（含 home area 限制） |
| Experiencing | 0-3 | UxOP 选修 |

## Foundations（12-15 学分）

- **CTDL**（Critical Thinking and Data Literacy）— 选修；缺额可用其他区域课程替代
- **HMW**（Habits, Mindsets, and Wellness）— 必修
- **E-Comm**（English Communication）— 必修
- **C-Comm**（Chinese Communication）— 必修
- 建议第一学年完成

## Broadening（12-18 学分）

- 区域：**A（Arts）、H（Humanities）、S（Science）、T（Technology）、SA（Social Analysis）**（⚠ 无 SUS，SUS 为 2025-26 新增）
- **home area**（主区域，按专业）：
  - SSCI 全部专业 → S
  - SENG 多数专业 → T；BIEN/CENG/EEEN → S+T；COSC → T
  - SBM 多数专业 → SA；WBB/EABU → 见专业特定要求
  - GCS → H+SA；QSA → SA；EVMT → SA（⚠ 2025-26 起为 SA+SUS）；ISDN → T
  - IIM / 双主修 / 双学位 / Joint-School → home area 取并集或按专业特定要求
- 核心要求：**home area 之外完成 12 学分**，且来自 **4 个不同区域**；不足可补任意区域（含 home area）
- 各专业的具体区域学分要求见 Program-specific Credit Requirements

## Experiencing（0-3 学分，选修）

- UxOP 四选一：UROP / UTOP / UPOP / UCOP
- UROP 需完成两个非 CC 预备课（UROP 1100/2100）+ 1 学分 CC 课（UROP 3200）

## 通用规则（全部 30 学分制版本适用）

- 课程须在列出的学年内修读才计入 CC；CC 课程列表逐年变动
- 同时列于多个区域的课程只能计入其中一个区域
- 计入 School/Major 要求的课程不可重复计入 CC（credit reuse 规则以各专业为准）
- 2022-23 年部分 CC 课曾用 CORE 前缀（如 CORE 1111 = PHYS 1003）；2023-24 起恢复科目代码，同课不可重复修

## 备注

- 2025-26 入学改为 v2（新增 SUS 区域）；2026-27 入学改为 v3（新增 HAIC 区域）
