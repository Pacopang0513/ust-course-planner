# Common Core — 2025-26 入学（30 学分制 v2）

> 适用入学年份：**2025-26**
> 总学分：**30**
> 来源：https://uce.ust.hk/web/courses_2025/curriculum.html

## 结构总览

| 层 | 学分 | 必修/选修 |
|---|---|---|
| Foundations | 12-15 | CTDL 选修，其余必修 |
| Broadening | 12-18 | 必修（含 home area 限制） |
| Experiencing | 0-3 | UxOP 选修 |

## Foundations（12-15 学分）

- **CTDL**（Critical Thinking and Data Literacy）— 选修；缺额可用 E-Comm（仅高级沟通课）、C-Comm、A、H、S、T、SA、SUS、UxOP 区域课程替代；转学分课程不可用于补 CTDL
- **HMW**（Habits, Mindsets, and Wellness）— 必修
- **E-Comm**（English Communication）— 必修
- **C-Comm**（Chinese Communication）— 必修
- 建议第一学年完成

## Broadening（12-18 学分）

- 区域：**A（Arts）、H（Humanities）、S（Science）、T（Technology）、SA（Social Analysis）、SUS（Sustainability）**
- **home area**（主区域，按专业）：
  - SSCI 全部专业 → S
  - SENG 多数专业 → T；BIEN/CENG/EEEN → S+T；COSC → T
  - SBM 多数专业 → SA；WBB/EABU → 专业特定要求
  - GCS → H+SA；QSA → SA；EVMT → SA+SUS
  - ISDN → T；IIM → 因学生而异，咨询 AIS
  - DDP / Joint-School → 专业特定要求
- 核心要求：**home area 之外完成 12 学分**，且来自 **4 个不同区域**（例：SSCI 学生须在 A/H/T/SA/SUS 中取 4 区；SBM 学生须在 A/H/S/T/SUS 中取 4 区）；不足可补任意区域（含 home area）
- 双主修/双学位/Joint-School：home area 为各 Major 的并集（例：S+T+SA 并集时，须 A/H/SUS 各 3 学分，余 3 学分任意 Broadening 区域）
- 各专业具体学分要求见 Program-specific Credit Requirements
- 转学分课程不可用于补 CTDL/UxOP

## Experiencing（0-3 学分，选修）

- UxOP 四选一：UROP / UTOP / UPOP / UCOP
- UROP 需两个非 CC 预备课（UROP 1100/2100）+ 1 学分 CC 课（UROP 3200）
- UPOP 需 1 学分非 CC 实习前培训 + 2 学分 UPOP CC 课
- UxOP 学分可替代 Broadening 区域学分

## 通用规则

- 课程须在列出的学年内修读才计入 CC；CC 课程列表逐年变动
- 同时列于多个区域的课程只能计入其中一个区域
- 计入 School/Major 要求的课程不可重复计入 CC（credit reuse 规则以各专业为准）

## 备注

- 与 2022-23~2024-25 版（v1）差异：新增 SUS 区域
- 2026-27 入学改为 v3（新增 HAIC 区域）
