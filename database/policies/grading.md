# grading.md — 课程评分体系

> 来源：HKUST Academic Regulations 2026-27 (AR 7) + Grading of Courses (Academic Quality Manual, 2025-08)

## 1. 成绩等级与绩点（AR 7.1）

| 等级 | 绩点 | 定义 |
|---|---|---|
| A+ | 4.3 | Excellent Performance |
| A | 4.0 | Excellent Performance |
| A- | 3.7 | Excellent Performance |
| B+ | 3.3 | Good Performance |
| B | 3.0 | Good Performance |
| B- | 2.7 | Good Performance |
| C+ | 2.3 | Satisfactory Performance |
| C | 2.0 | Satisfactory Performance |
| C- | 1.7 | Satisfactory Performance |
| D | 1.0 | Marginal Pass |
| F | 0.0 | Fail |

**无绩点等级**（不计入任何 GPA）：AU（旁听）、DI（Distinction，DI/PA/F 制）、P（Pass，P/F 制）、PA（Pass，DI/PA/F 制）、PP（允许续修，两/三段式项目课）、I（Incomplete，须下学期开学前转正，否则转 F）、T（转学分）、W（无惩罚退课）。

## 2. 官方课程成绩分布带（Guideline Bands，软性规范）

```
A (A+/A/A-) : 10-25%
B          : 25-40%
C          : 25-40%
D          :  5-10%
F          :  0-5%
```

- 软性指南（criterion-referenced），非强制 quota；偏离时教师须复核并向系主任说明
- 允许合理差异：不同学院之间；基础课（1000/2000 级）与高阶课（3000/4000 级）之间
- 目的：防止 grade inflation；各系按三年历史分布监控
- 第二评卷（second marking）：占总成绩 ≥30% 的评估且班级 ≥20 人时，须抽样双评

## 3. 相关流程

- 成绩复核（Grade Review）：成绩发布后 10 个工作日内书面申请，收费，复核可能降分
- 评分制：按课程 ILO 的 criterion-referenced 评分；教授推荐成绩，系主任批准
- 挂科：F 计入 CGA；毕业要求课程只能重修一次（再修需院长批准）；非挂科课程不可重修刷分

## 4. 适用范围

- 本表针对 UG 课程；PG 课程（5xxx/6xxx）评分规则不同
